# Intoduction
Plant is a social media platform focused on promoting natural growth of posts into forums with a dedicated community around them. This is acomplished with Plant's self-evolving post progression algorithm, which allows posts that meet the thresholds to evolve to dedicated forums and vice versa.
# Vision
Plant is a social forum platform that lets popular posts grow into their own dedicated forums. Unlike Reddit, Discord, or Tumblr, which require communities to be manually created before content can gather around them, Plant lets community formation emerge organically from what users are already engaging with.
# Measurable Metrics
- Growth/change in active users
- Number of posts that "graduate" per week
- Average lifespan/retention after forums spawn
- User engagement (posts, comments, likes, votes) within spawned forums vs. original posts
- Post release user quality survey results
> These are not ordered by importance.
# Financials
Plant will generate revenue through a few different avenues each with their own tiers of products, which are as follows:
1. Ads
	- Personal ads - a indivdual user can pay to have their post/forum advertised on explore page (different tiers of advertisement outreach).
	- Buisness ads - a company or buisness account memeber can go through the same proccess to promote their product across the platform. Additionally, higher buisness tiers allow for advertising to targetted demographics and outreach review reports.
2. Data collection and distribution
	- Communites/forums visted by user
	- queries made in search bar
	- rough geolocational data
	- user interactions with posts/forums
3. Premium subscription service
	- Premium customization options (avatar frames, higher quality profile img, animated profile backgrounds, unique user tags, etc.)
	- Limitations on amount of ads and where they are present
# Major Features

2. Personal account creation and customization.

4. Explore page.
5. Advertising/business account creation and customization
6. Favorites/Recent pages.
7. Individual profile pages.
8. Direct messaging between users

# Releases
Plant will be release incrementaly with 3 intial planned releases (1.0 - 1.2), allowing for developers to gain feedback on the core features from previous releases while also developing new features for the next release. This also allows users to see the active work being put into the platform and suggest features or changes to improve userability.
